## 现在在做

**文化墙效果图流水线** —— 一句话需求进，可编辑的分层 SVG 出。把原本 3 天的出图压到 2 小时。

链路是：短标题生图 → 效果图 → 高质量矢量化 → 浏览器里改字、改色、拆元素、导出。中间踩过的坑（中文渲染、扣费不可控、上游超时）都写进代码里了。
